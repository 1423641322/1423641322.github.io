## 项目展示

### 机器学习辅助的水凝胶基纳米酶构建及其抗氧化性能研究

国家级大学生创新创业训练计划项目。围绕口腔溃疡治疗中的氧化应激与药物滞留问题，结合随机森林建模、SHAP 特征分析、CeO₂ 纳米酶制备与抗氧化性能评价，探索数据驱动的材料设计流程。

### pH 响应型黏膜粘附胃溃疡修复体系

第十届全国大学生生物医学工程创新设计竞赛项目。围绕甲基壳聚糖 / 海藻酸钠双网络水凝胶，探索药物稳定负载、黏膜粘附与响应释放，并结合生物相容性测试及动物模型评价治疗效果。

- **可展开的项目详情**：按需查看研究过程、实验方法与结果。

- **阅读辅助**：提供跳转正文入口，并适配系统的减少动态效果偏好。
